# Домашна работа: Регистрация на ученик — класове, валидация и изключения

## Цел на задачата

Надградете конзолното приложение  **StudentRegistration**, като създадете клас `Student`, който съхранява данните за ученика и не допуска въвеждането на невалидни стойности.

Използвайте механизма за изключения (`Exception`), за да защитите правилата на класа.

## Задача 1. Създаване на клас Student

Създайте нов клас `Student` със следните свойства:

| Свойство | Тип | Описание |
|---|---|---|
| `Id` | `int` | Уникален идентификатор |
| `Name` | `string` | Име на ученика |
| `Age` | `int` | Възраст |
| `Grade` | `int` | Клас |
| `AverageScore` | `double` | Среден успех |
| `Fee` | `decimal` | Такса |
| `HasScholarship` | `bool` | Получава ли стипендия |
| `ClassLetter` | `char` | Паралелка |
| `BirthDate` | `DateTime` | Дата на раждане |

**Изисквания:**

1. Добавете конструктор, който приема `id` и `name`.
2. `Id` трябва да може да се задава само при създаване на обекта.
3. Останалите свойства трябва да позволяват задаване на стойности, като при необходимост извършват валидация.

## Задача 2. Валидация на данните

Реализирайте следните проверки в класа `Student`:

| Свойство | Условие | Изключение |
|---|---|---|
| `Id` | Положително цяло число | `ArgumentOutOfRangeException` |
| `Name` | Не може да бъде празно или само интервали | `ArgumentException` |
| `Age` | Между 6 и 20 години включително | `ArgumentOutOfRangeException` |
| `Grade` | Между 1 и 12 включително | `ArgumentOutOfRangeException` |
| `AverageScore` | Между 2.00 и 6.00 включително | `ArgumentOutOfRangeException` |
| `Fee` | Не може да бъде отрицателна | `ArgumentOutOfRangeException` |
| `ClassLetter` | Трябва да е буква | `ArgumentException` |
| `BirthDate` | Не може да е бъдеща дата | `ArgumentOutOfRangeException` |

За свойството `HasScholarship` не е необходима допълнителна проверка в класа, тъй като типът `bool` допуска само `true` или `false`.

**Пример за валидация:**

```csharp
if (age < 6 || age > 20)
{
    throw new ArgumentOutOfRangeException(
        nameof(age),
        "Възрастта трябва да бъде между 6 и 20 години.");
}
```

Реализирайте останалите проверки самостоятелно.

## Задача 3. Промяна на Program.cs

Променете съществуващата програма така, че:

1. Реализирайте автоматично генериране на уникален идентификатор (Id) за всеки ученик чрез статично поле nextId в класа Program.
2. При невалиден формат на въведената стойност програмата изисква повторно въвеждане.
3. При стойност, която нарушава правилата на класа `Student`, възниква съответното изключение.
4. Изключението се прихваща в `Program.cs` чрез `try-catch`, извежда се съобщение и потребителят въвежда стойността отново.
5. При успешно въвеждане данните се съхраняват в обект от тип `Student`.
6. Програмата извежда данните чрез свойствата на създадения обект.

**Важно:** Проверките за допустимите стойности трябва да бъдат реализирани в класа `Student`, а не само в `Program.cs`.

## Задача 4. Проверка на програмата

Тествайте програмата със следните стойности:

| Въведена стойност | Очаквано поведение |
|---|---|
| `Id = -2` | Изключение за невалиден идентификатор |
| `Name = "   "` | Изключение за празно име |
| `Age = 150` | Изключение за невалидна възраст |
| `Grade = 13` | Изключение за невалиден клас |
| `AverageScore = 7.00` | Изключение за невалиден успех |
| `Fee = -50` | Изключение за отрицателна такса |
| `ClassLetter = '5'` | Изключение за невалидна паралелка |
| `BirthDate = 01.01.2030` | Изключение за бъдеща дата |

При всяка невалидна стойност програмата трябва да позволи корекция, без да прекратява работата си.

## Критерии за оценяване

- Създаден е клас `Student` с подходящи свойства и конструктор.
- Реализирани са всички посочени валидации.
- Използвани са подходящи типове изключения.
- Изключенията се обработват чрез `try-catch`.
- При невалидни данни програмата не прекратява работата си.
- Данните се съхраняват и извеждат чрез обект от клас `Student`.

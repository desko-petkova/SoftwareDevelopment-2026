# Упражнение: Безопасно въвеждане на данни с TryParse()
Създайте конзолна програма StudentRegistration, която въвежда данни за ученик.
Потребителят трябва да въведе:
Име
Възраст
Клас
Среден успех
Такса
Има ли право на стипендия
Буква на паралелката
Дата на раждане

Използвайте подходящ тип данни за всяка стойност.
Данни	          Тип
Име	            string
Възраст	        int
Клас	        byte
Среден успех	double
Такса	        decimal
Стипендия	    bool
Паралелка	    char
Дата на раждане	DateTime


### Задача 1 — int.TryParse()
Въведете възраст.
Console.Write("Възраст: ");

if (int.TryParse(Console.ReadLine(), out int age))
{
    Console.WriteLine($"Възраст: {age}");
}
else
{
    Console.WriteLine("Невалидна възраст.");
}

Проверете програмата с:
16

и:
шестнадесет

### Задача 2 — byte.TryParse()
Въведете клас на ученика:
11

Използвайте:
byte.TryParse(...)

Проверете какво става при:
300

### Задача 3 — double.TryParse()
Въведете среден успех:
5.75

или според регионалните настройки:
5,75

Използвайте:
double.TryParse(...)

При успешен вход изведете:
Среден успех: 5.75

### Задача 4 — decimal.TryParse()
Въведете парична стойност:
125.50

Използвайте:
decimal.TryParse(...)


### Задача 5 — bool.TryParse()

Въведете:
true

или:
false

if (bool.TryParse(Console.ReadLine(), out bool hasScholarship))
{
    Console.WriteLine(hasScholarship);
}

След това опитайте:
да

и:
не

### Задача 6 — char.TryParse()
Въведете буква на паралелката:
A

или:
Г

Използвайте:
char.TryParse(...)

После опитайте:
AB


### Задача 7 — DateTime
Въведете дата на раждане:
15.03.2010

Първо пробвайте:
DateTime birthDate = DateTime.Parse(Console.ReadLine());

След това въведете:
утре

или:
35.17.2020


След това заменете Parse() с:
Console.Write("Дата на раждане: ");

if (DateTime.TryParse(Console.ReadLine(), out DateTime birthDate))
{
    Console.WriteLine($"Дата: {birthDate:d}");
}
else
{
    Console.WriteLine("Невалидна дата.");
}



### Задача 8 — повтаряне до валиден вход
До момента при грешка само извеждахме съобщение.
Сега направете програмата да пита, докато потребителят въведе правилна дата:
DateTime birthDate;

while (true)
{
    Console.Write("Дата на раждане: ");

    if (DateTime.TryParse(Console.ReadLine(), out birthDate))
    {
        break;
    }

    Console.WriteLine("Невалидна дата. Опитайте отново.");
}

Направете същото и за възрастта.
Задача 9 — по-кратък вариант
Може да се използва и:
int age;

while (!int.TryParse(Console.ReadLine(), out age))
{
    Console.WriteLine("Въведете цяло число:");
}
